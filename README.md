### BACKEND for a WebAPI 
----
#### IT IS WRITTEN IN C# 

It is designed for a Shoe Shop implementing CRUD.

The project is a .NET Web API project, and it is using .NET Core. It is aswell a REST API because I implemented all the main HTTP requests (GET,POST,(PUT),DELETE)

The database used was SQLite, but can easily implement MySQL or other.
The architecture design is the standard 3-layer:                                                              

Controller → Logic → Repository (+ Database)

It can be easily adjusted for other purposes
